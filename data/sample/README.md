# Sample Data

Small test datasets for unit tests, CI/CD, and sharing.

## Creating Sample Data

Run this script to generate sample data from your real datasets:

```r
source("scripts/create_sample_data.r")
```

## Current Files

After running `create_sample_data.r`, you should have:

- `test_chr1.rds` - Sample of chromosome 1 data (~500 rows)
- `golden_output.rds` - Expected output for regression tests (auto-generated by tests)

## File Size Limit

Keep files under 10 MB. If files are too large:

```r
# Edit scripts/create_sample_data.r
n_sample_rows <- 100  # Reduce from 500 to 100
```

## Usage in Tests

```r
# In test files
sample_data <- readRDS("data/sample/test_chr1.rds")
```
